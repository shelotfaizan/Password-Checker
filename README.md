# Password Checker

A simple **Password Checker** built using Python. This project checks whether a password meets basic security requirements and helps users understand password validation.

## Features

* Checks password length
* Checks for uppercase letters
* Checks for lowercase letters
* Checks for numbers
* Checks for special characters
* Gives feedback about password strength

## Password Requirements

A strong password should contain:

* At least 8 characters
* At least one uppercase letter
* At least one lowercase letter
* At least one number
* At least one special character

## Technologies Used

* **Python**
* String methods
* Conditional statements
* Loops
